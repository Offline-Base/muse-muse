# Sources

Where the values in `tokens.md` come from, read in October 2026. facebook.com blocks scripted reads, so Facebook's values come from dated public copies of its CSS variables. Values are facts from these pages, written in our own words.

## Facebook product tokens

- GatoJustiniano/gatojustiniano.github.io, https://github.com/GatoJustiniano/gatojustiniano.github.io: a 2021 copy of Facebook's CSS variables, the older values (accent #1877F2, dark wash #18191A).
- ahmedelmansory1911/Cloned-Facebook, https://github.com/ahmedelmansory1911/Cloned-Facebook: a 2024 copy with the current light and dark tokens.
- imgnxtion/freeonlinemarketplace, https://github.com/imgnxtion/freeonlinemarketplace: a second 2024 copy that confirms them.
- SysAdminDoc/HushFacebookWeb, https://github.com/SysAdminDoc/HushFacebookWeb: values read from the live site in October 2026.
- amitrv26/FB-LOX-UXR, https://github.com/amitrv26/FB-LOX-UXR: a 2026 research prototype that cites Facebook's internal tokens (type scale, radii, sizes, motion).
- Ahmad Shadeed, "CSS Findings From The New Facebook Design", https://ishadeed.com/article/new-facebook-css/: a 2020 walkthrough of the redesign's layout, elevation and variables.

## Meta brand

- meta.com, https://www.meta.com/: the live stylesheet for Meta blue #0064E0, the text and border grays, the gradients and the font stack that falls back to Montserrat.
- Meta for Developers docs, https://developers.facebook.com/docs/: the live stylesheet for the same palette and easing.
- Meta brand resources, https://www.meta.com/brand/resources/: what Meta's marks are, so products never use them.
- Wikimedia Commons renders of the Meta symbol and the 2024 Meta AI logo, https://commons.wikimedia.org/: to sample their colors and to know what not to imitate.

## Meta Horizon design

- Typography, https://developers.meta.com/horizon/design/styles_typography/: the Horizon OS type scale, Inter as the developer typeface, minimum sizes, no italics.
- Fonts and icons, https://developers.meta.com/horizon/design/fonts-icons/: outlined icons on a 24 grid with a 20 live area.
- Color, https://developers.meta.com/horizon/design/styles_color/: semantic color roles, AA contrast, light and dark through prefers-color-scheme.
- Immersive 2D apps, https://developers.meta.com/horizon/design/pwa/: responsive panel sizes for 2D web apps.
- Spatial SDK UI Set reference, https://developers.meta.com/horizon/: radii for dialogs, panels, cards, list items and buttons, and hit target sizes.

## AI labels

- TechCrunch, "Meta is changing its 'Made with AI' tag to 'AI Info' tag" (July 1, 2024), https://techcrunch.com/2024/07/01/meta-changes-its-label-from-made-with-ai-to-ai-info-to-indicate-use-of-ai-in-photos/: Meta labels media a model made or changed, which is why AI output gets a visible label here.
