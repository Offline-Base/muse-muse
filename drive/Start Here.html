Start it

On a Mac with Apple silicon

  1. Double-click Start (Mac).command on this drive. A Terminal window opens.
  2. If macOS says it can't be opened, open System Settings, then Privacy & Security, scroll down and click Open Anyway next to its name. Then double-click it again. This drive's launchers aren't signed yet.
  3. If macOS asks whether Terminal may open files on a removable volume, click Allow.
  4. Press Return to copy the model to your Mac (recommended), then wait. The chat opens in your browser.

On a Windows PC

  1. Double-click Start (Windows).cmd on this drive. A window opens.
  2. If Windows says it protected your PC, click More info, then Run anyway. This drive's launchers aren't signed yet.
  3. Press Enter to copy the model to your PC (recommended), then wait. The chat opens in your browser.

Windows PCs with Smart App Control on aren't supported yet. To see whether yours has it on, open Windows Security, then App & browser control, then Smart App Control settings.

The first start can take up to 10 minutes while the model loads, and the window shows the server's messages as they scroll by. Keep the window open while you chat, and close it to stop the model.

The drive doesn't run on Linux or on a Mac with an Intel chip. On those, the same files are free on Hugging Face, and the model's page is {{PAGE_URL}}.

Chat with it

The chat opens at http://127.0.0.1:9931, or the next free port, and only your computer can reach it. Each new chat starts with the system message the model was trained with. If one doesn't, paste this into the chat's settings as its system message:

Check the files

Double-click Verify (Mac).command or Verify (Windows).cmd. It checks every file on the drive against SHA256SUMS, and changes nothing. The same checksums are on the model's Hugging Face page.
